# 0005 - Native Flutter map from offline-prepared, content-addressed packs

- Status: accepted
- Date: 2026-10-06 (M3, PR #4; all 13 maps in M5, PR #7)
- Source: [implementation strategy §5](../IMPLEMENTATION_STRATEGY.md#5-map-strategy); [M3 status](../qualification/m3/STATUS.md), [M5 status](../qualification/m5/STATUS.md)

## Context and problem

The reference rendered maps as HTML/SVG/JavaScript in WebView2, which the strategy removes. The artwork is large: shared defs, multilevel floors, Labs raster tiles and Icebreaker's 16 raster floors. It must render aligned with calibrated markers, with no SVG parsing during pan/zoom and no runtime network dependency.

## Decision

**Build time.** Offline tooling (`dart run tool/maps/prepare.dart acquire|rebuild|normalize|compile|validate|promote|assets`):

- downloads the artwork from tarkov.dev;
- normalises each SVG floor and compiles it to `.vec` with `vector_graphics_compiler` (`tool/maps/pack.dart:75-81`);
- writes an immutable generation under `assets/maps/versions/<sha256-of-manifest>/`;
- swaps `assets/maps/active.json` atomically (`pack.dart:1452-1484`).

**Runtime.**

- Only the `vector_graphics` runtime ships (`pubspec.yaml:15`), loading pictures from `.vec` (`lib/maps/native_map_scene.dart:127-133`). There is no `flutter_svg`.
- Raster floors and tiles are drawn in the same calibrated frame.
- `CustomPaint` with a domain `MapViewTransform` keeps markers screen-sized and drives hit testing (`lib/ui/map_workspace.dart:349-392`; `lib/application/map_controller.dart:466-596`).
- Decoded resources sit in a 192 MiB LRU (`native_map_scene.dart:23-35`).
- The loader checks structure and versions, not content hashes (`lib/maps/prepared_map_loader.dart:44-124`).

## Rejected alternative

- **Keep a WebView2/HTML map.** Removed by product scope.
- **Parse SVG at runtime with `flutter_svg`.** Rejected for its parse cost on each load and incomplete CSS/filter support. Precompilation lets each map be checked offline for fidelity.

## Consequences

- **Updating artwork is an offline tooling step** that produces a new generation; old generations are kept.
- **`pubspec.yaml` lists every tile directory**, generated by `prepare.dart assets`.
- **Runtime trusts the bundled bytes.** A corrupt pack surfaces as a load error on the canvas.
- **Reversal cost: high.** Rendering, the pack format, the tooling and the calibration evidence all depend on this decision.
