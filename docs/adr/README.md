# Architecture Decision Records

Short [MADR](https://adr.github.io/madr/) records of decisions the code implements. Accepted ADRs are immutable: change a decision by writing a new ADR that supersedes the old one, then update the index in [openspec/architecture.md](../../openspec/architecture.md#in-force-adrs). Decisions that are planned but not built belong in the [roadmap](../../openspec/roadmap.md).

ADRs 0001-0007 were written on 2026-10-07, when the project adopted Specwright. They record decisions that were already in place, so each one's date is when its code merged to `main`.
